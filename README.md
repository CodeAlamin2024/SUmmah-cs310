# SUmmah

**CS310 Mobile Application Development - Group 35**

MasjidConnect is a proposed Flutter mobile application for university students to view their campus masjid's prayer and iqamah times, track the next prayer with a live countdown, check Jumu'ah information, and read mosque announcements.

The initial use case is the Sabancı University masjid. The project will begin with sample timetable data; official schedules will require verification with the masjid administration before real-world use.

## Planned core features

- Daily Fajr, Dhuhr, Asr, Maghrib, and Isha prayer and iqamah timetable
- Next-prayer / next-iqamah countdown
- Jumu'ah schedule information
- Mosque announcements
- Basic authorized schedule and announcement editing

## Optional features

- Prayer reminders
- Hijri calendar and Qibla direction
- Full-screen mosque display mode

## Proposed technology

- Flutter and Dart for the mobile application
- Firebase Cloud Firestore for mosque schedules and announcements
- Firebase Authentication for authorized administrator access

The technology choices are proposals and may be revised during implementation.
